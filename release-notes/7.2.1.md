# 7.2.1

## What changed

- Every dependency now comes from the public npm registry; the two optional internal packages are
  removed. The lockfile tree is otherwise identical to 7.2.0 (no version, integrity or URL change).
- `lib/config/fetchRetry.js` implements the chain-RPC retry semantics the production image used:
  5 attempts, a 5 s timeout per attempt, retry on non-2xx and on transient network errors.
- The container image is built and pushed by this repository's release workflow on the release tag.

## Why

- The build must not depend on a private package registry; GitHub is the primary repository.
- Without the internal package the fallback had no per-attempt timeout, so a hung RPC connection
  could stall a member. The semantics now live in this repository and are unit-tested.

## Deploying

Roll one member at a time. Promote the next member only after the previous one shows
`/health-check` `bootCheck.ok: true`, `/version` `7.2.1`, and `submitpart` + `setrand` on chain.
